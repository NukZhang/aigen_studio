# AIGen Studio 教程中心

欢迎使用 AIGen Studio 教程中心！这里汇集了项目开发指南和操作手册。

## 快速入门

### 1. 创建新对话

点击工作区顶部的"新建对话"按钮，开始创建一个新的应用项目。

### 2. 输入需求

在对话框中描述您的需求，例如：
```
创建一个简单的待办事项管理应用，支持添加、删除和标记完成功能
```

### 3. 确认理解

AI 会分析您的需求并生成理解说明，确认无误后点击"确认，开始生成代码"。

### 4. 预览应用

代码生成完成后，点击"确认启动"按钮，即可在预览面板中查看应用效果。

### 5. 查看和编辑代码

切换到"文件"标签页，可以查看生成的代码结构并编辑文件。

## 功能说明

### 对话功能

- **需求输入**：自然语言描述您的应用需求
- **需求理解**：AI 分析并理解您的需求
- **代码生成**：基于理解自动生成前后端代码
- **实时反馈**：查看 AI 的思考过程和操作步骤

### 文件管理

- **浏览文件树**：查看生成的项目结构
- **编辑文件**：在线编辑代码文件
- **创建文件**：添加新的文件
- **删除文件**：删除不需要的文件

### 预览功能

- **实时预览**：查看应用运行效果
- **自动刷新**：代码修改后自动刷新预览
- **多窗口支持**：同时预览多个页面

## 常见问题

### Q: 如何修改生成的代码？

A: 切换到"文件"标签页，选择要修改的文件，在右侧编辑器中进行编辑。

### Q: 如何重新生成代码？

A: 创建新的对话或删除现有对话后重新创建。

### Q: 支持哪些技术栈？

A: 当前支持 Vue 3 前端和 Spring Boot 后端。

### Q: 生成的代码如何发布？

A: "发布"功能正在开发中，敬请期待。

## 进阶使用

### 创建复杂应用

对于复杂的应用，建议分步骤描述需求：

1. 首先描述整体架构和核心功能
2. 然后详细说明每个功能模块
3. 最后说明数据模型和接口需求

### 优化代码质量

- 使用清晰的描述语言
- 提供具体的功能需求
- 说明数据结构和接口规范

### 调试技巧

- 查看对话历史了解 AI 的思考过程
- 检查生成的代码结构
- 使用预览功能验证功能实现
