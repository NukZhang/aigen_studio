# AIGen Studio 快速入门指南

本指南将帮助你在 5 分钟内启动 AIGen Studio 并通过自然语言对话完成第一个应用的开发。

## 第一步：环境准备

确保你已经安装了以下软件：

```bash
# 检查 Java 版本（需要 17+）
java -version

# 检查 Maven 版本
mvn -version

# 检查 Node.js 版本（需要 18+）
node -v
```

如果未安装，请先安装这些依赖。

## 第二步：启动项目

### 方式一：一键启动（推荐）

```bash
cd aigen_studio
chmod +x scripts/start-all.sh
./scripts/start-all.sh
```

### 方式二：分别启动

**启动后端：**
```bash
cd backend
mvn spring-boot:run
```

**启动前端（新终端）：**
```bash
cd frontend
npm install
npm run dev
```

## 第三步：访问系统

打开浏览器访问：

- 前端界面：http://localhost:3000
- 后端 API：http://localhost:8080/api
- H2 控制台：http://localhost:8080/api/h2-console

## 第四步：创建第一个对话

1. 点击右上角"新建对话"按钮
2. 在聊天框中输入你的需求（自然语言）
3. 选择 AI 模型（可选）
4. 点击发送

**示例需求：**
> 我想创建一个简单的任务管理应用，可以添加、编辑、删除任务，并且支持任务状态标记（完成/未完成）。

## 第五步：确认理解

AI 会分析你的需求并生成理解结果，包括：
- 项目目标
- 核心功能
- 技术栈
- 项目结构

查看理解结果后：
- 如果正确，点击"确认，开始生成代码"
- 如果有误，点击"不正确，需要修改"并补充说明

## 第六步：等待代码生成

系统会自动生成代码，包括：
- 前端 Vue 3 项目
- 后端 Spring Boot 项目
- 配置文件
- OpenAPI 规范

实时查看生成日志和进度。

## 第七步：启动预览

代码生成完成后：

1. 点击"确认启动"按钮
2. 系统自动启动前后端服务
3. 在"预览"标签页中查看应用运行效果

## 第八步：查看和编辑代码

1. 切换到"文件"标签页
2. 在左侧文件树中浏览生成的代码
3. 点击文件查看内容
4. 在右侧编辑器中修改代码
5. 保存修改后，刷新预览查看效果

**代码输出位置：**
- 默认路径：`generated-code/conversation-{id}/`
- 配置项：`iflow.sdk.output-dir`

## 第九步：学习教程

1. 切换到"教程"标签页
2. 浏览内置教程目录
3. 点击教程文件查看内容
4. 学习最佳实践和高级功能

## 常见问题

### 后端启动失败

**问题：** 端口 8080 被占用

**解决方案：**
```bash
# 查找占用端口的进程
lsof -i :8080

# 杀死进程
kill -9 <PID>
```

### 前端启动失败

**问题：** npm install 失败

**解决方案：**
```bash
# 清除缓存重新安装
rm -rf node_modules package-lock.json
npm install
```

### 预览启动失败

**问题：** 预览服务无法启动

**解决方案：**
```bash
# 查看预览日志
tail -f data/preview-{conversationId}-frontend.log
tail -f data/preview-{conversationId}-backend.log

# 检查端口占用
lsof -i :3001
lsof -i :8081
```

### 代码生成失败

**问题：** iFlow SDK 连接失败

**解决方案：**
- 检查 `IFLOW_API_KEY` 环境变量是否配置
- 确认 iFlow 服务是否可访问
- 查看后端日志：`tail -f data/preview-*.log`

### 对话无响应

**问题：** 发送消息后 AI 没有响应

**解决方案：**
- 检查网络连接
- 查看浏览器控制台错误
- 查看后端日志
- 尝试重新创建对话

## 快捷键和技巧

### 工作区快捷键

- `Ctrl/Cmd + N` - 新建对话
- `Ctrl/Cmd + K` - 聚焦输入框
- `Ctrl/Cmd + Enter` - 发送消息
- `Ctrl/Cmd + S` - 保存当前文件（编辑器中）
- `Ctrl/Cmd + F` - 查找文件

### 使用技巧

1. **需求描述要清晰**：详细描述功能、界面、交互等
2. **分阶段开发**：先完成核心功能，再逐步添加特性
3. **及时保存代码**：编辑代码后记得保存
4. **查看日志**：遇到问题查看预览日志
5. **学习教程**：教程中有丰富的示例和最佳实践
