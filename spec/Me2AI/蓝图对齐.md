# 蓝图对齐

蓝图主链路
- 需求转译 -> 识别标准功能 -> 功能拆解 -> 技术方案输出/产品方案输出/测试方案输出
- 创建物理实体 -> 创建前端界面 -> 创建交互逻辑 -> 创建前端路由 -> 创建数据接口 -> 业务逻辑实现
- 代码提交仓库 -> 功能测试/性能测试/安全测试 -> CI -> CD

PoC 映射
- 需求转译/功能拆解：由 IR 编辑器 + 规则约束完成
- 技术方案输出/测试方案输出：生成 docs 占位文件即可
- 创建实体/界面/路由/接口/逻辑：由 Skills 生成最小可运行骨架
- 代码提交仓库：由 GitLab MCP 完成
- 测试与 CI/CD：由 GitLab pipeline + evidence 落盘完成
