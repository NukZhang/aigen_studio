# 需求描述 PoC

背景
- 验证 AICoding 规则包 + IR 最小规范 + MCP/Skills 的可行性
- 平台技术栈：前端 Vue，后端 Java Spring Boot
- AICoding 执行器：iFlow（Java SDK 接入）https://platform.iflow.cn/cli/sdk/sdk-java

用户角色
- 平台管理员：维护规则、配置 MCP、维护模板仓库地址与 token
- 需求使用者：录入需求、编辑 IR、发起生成、查看结果

PoC 范围
- 管理后台
  - 需求录入
  - IR 在线编辑器
  - 作业 Job 发起与运行日志
  - 产出物预览与下载（可先占位）
- 作业执行
  - 拉取/创建 GitLab 仓库分支
  - 生成前端 Vue 工程骨架 + 1 个示例页面
  - 生成后端 Spring Boot 工程骨架 + 1 组示例接口
  - 生成/更新 OpenAPI
  - OpenAPI breaking-change 检查 + TS SDK 生成
  - 触发 GitLab pipeline
- 可选增强
  - Gravitee 4.0 灰度策略导入导出与发布联动

## 本 PoC 的核心闭环
- 需求录入与 IR 编辑
- 触发作业并调用 iFlow 执行生成
- OpenAPI breaking 检查 + TS SDK 生成
- GitLab CI 触发与 evidence 证据链落盘
- 可选：Gravitee 灰度策略导入导出与发布联动

# 验收标准 PoC

功能验收
- 可以在管理后台创建一个需求并生成一个 IR
- 点击生成后：
  - 目标 GitLab 仓库出现一个新分支与提交
  - 前端 Vue 工程可本地启动并看到示例页面
  - 后端 Spring Boot 工程可启动并提供示例接口
  - openapi.yaml 被生成或更新
  - 生成 TS SDK 输出到指定目录
  - GitLab pipeline 被触发，结果可追溯
  - evidence manifest 落盘，记录 inputs outputs gates

质量门禁
- IR 校验通过
- OpenAPI breaking 检查通过或明确报告差异
- 基础构建通过（frontend build + backend build）

## 第三阶段：AI Developer 界面改造

    - **教程**：项目开发指南和文档

### 功能融合方案

#### 保留并融合的功能
| AI Developer 功能 | 现有 AIGen 功能 | 融合方式 |
|------------------|----------------|----------|
| 对话历史 | GenerationJob | Job 作为对话会话，Job.logs 作为对话内容 |
| 工具调用展示 | 作业日志 | logs 中记录工具调用信息，解析展示 |
| 待办事项列表 | IR 文档 | 从 IR 的 modules/features 解析任务 |
| 代码预览 | Artifact | Artifact.content 展示代码 |
| 项目名称 | Requirement.title | 显示需求标题作为项目名 |
| 文件操作结果 | 产出物管理 | Artifact 关联到文件操作结果 |

#### 需要丢弃的功能
| AI Developer 功能 | 丢弃原因 |
|------------------|----------|
| 多用户协作（在线用户、分享按钮） | AIGen Studio 是单用户个人开发工具，无需协作功能 |
| Firebase 集成 | 需要 Firebase 账号和配置，超出当前 PoC 范围 |
| AdMob 广告集成 | 需要 Google AdMob 账号，超出当前 PoC 范围 |
| GitHub 集成 | 已有 GitLab 集成，无需重复 |
| Flutter Web 实时预览服务 | 后端没有实时预览服务能力，使用占位符替代 |
| 图片生成工具 | 当前只集成 iFlow SDK 生成代码，无图像生成能力 |
| Notion 保存功能 | 需要第三方集成，当前无此需求 |

#### 需要新增的功能
| 功能 | 实现方式 |
|------|----------|
| 代码编辑器 | 集成 Monaco Editor（前端已有使用经验） |
| 待办事项管理 | 从 IR 文档解析任务，新增 TodoList 组件 |
| 文件浏览器 | 树形结构展示生成的项目文件 |
| 预览功能 | iframe 嵌入或外部链接（暂不实现实时预览） |
| 发布界面 | 集成 GitLab 提交和发布功能 |
| 脚本执行 | 显示构建脚本和执行结果 |
| 教程文档 | 从 IR 或 Markdown 文件解析 |

### 技术实现要点

#### 前端改造
1. **主页面布局改造** (`App.vue`)
   - 从管理后台布局 → 左右分栏 AI Developer 布局
   - 左侧：对话输入框 + 对话历史列表
   - 右侧：标签页（代码编辑器、预览、产出物列表）

2. **对话组件**
   - `ChatConversation.vue`：对话历史展示
   - `MessageBubble.vue`：单个消息气泡（用户/AI）
   - `ToolCallDisplay.vue`：工具调用结果展示
   - `TodoList.vue`：待办事项列表

3. **工作区组件**
   - `CodeEditor.vue`：Monaco Editor 代码编辑器
   - `ArtifactPreview.vue`：产出物预览
   - `JobLogsViewer.vue`：作业日志查看器
   - `FileBrowser.vue`：文件浏览器（树形结构）
   - `PublishPanel.vue`：发布到 GitLab 面板
   - `ScriptPanel.vue`：脚本执行面板
   - `TutorialPanel.vue`：教程文档面板

4. **API 层改造**
   - 新增 `/api/conversations` 相关接口（复用现有 Job 接口）
   - 解析 Job.logs 格式化为对话数据
   - 从 IR 文档提取待办事项

#### 后端改造
1. **Controller 层**
   - 新增 `ConversationController`（或复用 `GenerationJobController`）
   - 提供对话格式化输出接口

2. **Service 层**
   - `ConversationService`：将 Job.logs 转换为对话格式
   - `TodoService`：从 IR 解析待办事项

3. **DTO 层**
   - `ConversationDTO`：对话数据结构
   - `MessageDTO`：消息数据结构
   - `ToolCallDTO`：工具调用数据结构
   - `TodoItemDTO`：待办事项数据结构
