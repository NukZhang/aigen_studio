# 技术约束

前后端
- 前端：Vue 工程（前后端分离）
- 后端：Spring Boot 工程（前后端分离）

AICoding 执行器
- 使用 iFlow Java SDK 集成 iFlow CLI
- Java 版本要求：11+
- iFlow CLI 版本要求：0.2.24+
- SDK 通过 IFlowClient 与 iFlow CLI 交互，支持消息流与工具调用

安全
- 默认禁止文件系统访问与工具自动执行
- PoC 可使用选择性自动执行，且仅允许访问工作目录白名单
- 所有 token 只通过环境变量注入，不落盘到仓库
