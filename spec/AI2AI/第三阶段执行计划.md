# 第三阶段执行计划：AI Developer 界面改造

## 目标

将 AIGen Studio 的前端界面改造为 GenSpark AI Developer 模式，实现对话驱动开发，支持实时对话、代码生成、文件浏览、预览等功能的全链路打通。

## 核心功能

### 1. 实时对话交互（流式响应）
- **功能描述**：在对话区与 AI 实时交互，支持流式响应（逐字显示）
- **技术实现**：
  - 前端：WebSocket 或 Server-Sent Events 接收流式消息
  - 后端：集成 iFlow SDK，支持流式输出
  - 消息格式：支持 Markdown、代码块、工具调用展示
- **数据来源**：调用 iFlow SDK 生成 AI 回复

### 2. 待办事项管理
- **功能描述**：从 Job.logs 的 Deep Thought 部分解析待办事项
- **数据来源**：`Job.logs` 中的深度思考内容
- **解析逻辑**：识别任务关键词（如 "待办事项"、"任务列表"、"下一步"）
- **功能**：展示待办列表、更新状态（待办/进行中/已完成）

### 3. 代码编辑器（只读）
- **功能描述**：展示生成的代码文件，支持语法高亮
- **技术实现**：Monaco Editor（只读模式）
- **数据来源**：`generated-code/job-{id}` 目录中的文件
- **功能**：
  - 展示文件内容
  - 语法高亮
  - 显示文件路径和类型
  - 后续支持编辑并保存

### 4. 文件浏览器
- **功能描述**：树形结构展示生成的项目文件
- **数据来源**：本地 `generated-code` 目录
- **功能**：
  - 树形展示文件和文件夹
  - 点击文件查看内容
  - 支持文件下载
  - 按文件类型筛选

### 5. 预览功能
- **功能描述**：预览生成的应用界面
- **实现方式**：
  - 生成的项目包含 mock 数据
  - 启动生成项目到独立端口（如 3001、3002）
  - 使用 iframe 嵌入预览页面
- **Mock 策略**：
  - 生成的前端代码包含示例数据
  - 预览的是真实页面（非 mock）
  - 主项目不需要 mock

### 6. 生成的后端服务
- **功能描述**：Job 生成的对应后端服务
- **数据来源**：通过 Job ID 关联到对应的后端项目
- **功能**：
  - 查看后端代码
  - 查看 API 接口
  - 测试接口（可选）

### 7. 全链路测试
- **测试场景**：生成一个完整的待办事项应用
- **测试步骤**：
  1. 创建需求
  2. 编辑 IR
  3. 发起生成作业
  4. 对话区查看生成过程
  5. 待办事项从 Deep Thought 解析
  6. 文件浏览器查看生成的文件
  7. 代码编辑器查看代码
  8. 预览功能测试（如果可用）
  9. 验证所有功能正常

## 技术架构

### 前端技术栈
- Vue 3 + TypeScript
- Element Plus（UI 组件库）
- Monaco Editor（代码编辑器）
- WebSocket/EventSource（流式响应）
- Axios（HTTP 客户端）
- Pinia（状态管理）

### 后端技术栈
- Spring Boot 3.2.0
- Spring WebSocket（流式响应）
- iFlow SDK（AI 代码生成）
- JPA（数据持久化）
