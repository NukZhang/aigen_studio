# 第四阶段执行计划：工作区对话流与预览能力完善

## 执行日期
2026-02-02

## 目标
- 修复对话流在代码生成后样式变乱/变窄的问题，保证对话区宽度与气泡排版稳定
- 增加“确认启动服务”环节，避免自动启动
- 合并文件浏览器与代码编辑能力，支持对生成目录的可控编辑
- 支持预览服务启动/停止/重启，并在对话流与预览区展示状态与链接

## 关键约束
- 对话区宽度、气泡最大宽度、字体/行高/间距、对齐方式 **固定不变**
- **任何消息类型**（AI 回复/工具调用/日志/状态）不得改变对话区布局宽度
- 文件操作仅允许 `generated-code/job-{id}` 范围内
- 预览端口从 **新生成项目的 `application.yml`** 读取，且 **避开 3000/8080**
- 当前仅允许 **一个 job** 的前后端服务运行，预留多实例扩展能力

## 技术栈
- 前端：Vue 3 + TypeScript + Element Plus + Monaco Editor
- 后端：Spring Boot 3.2 + JPA + ProcessBuilder
- 配置读取：SnakeYAML（或 Spring 的 Yaml 解析）

## 任务分解

### Task 1：对话流样式稳定性修复
**目标**：锁定左侧对话区宽度与气泡排版  
**要点**：
- 固定对话区容器宽度与最小/最大宽度
- 统一气泡最大宽度与排版规则
- 对工具调用/日志/状态消息的样式进行隔离

### Task 2：确认启动服务流程
**目标**：生成完成后由用户确认启动  
**要点**：
- 对话流尾部插入“确认启动”按钮
- 点击后触发后端启动预览服务 API
- 未点击前不启动任何预览服务

### Task 3：文件浏览 + 代码编辑合并面板
**目标**：同一面板完成浏览与编辑  
**要点**：
- 左侧文件树 + 右侧编辑器
- 仅文本文件可编辑，二进制文件只读/不展示
- 保存按钮 + 成功/失败提示

### Task 4：文件操作 API
**目标**：支持新建/删除/重命名/新建文件夹/上传  
**建议接口**：
- `GET /api/files/job/{jobId}/tree`
- `GET /api/files/job/{jobId}/content?path=...`
- `PUT /api/files/job/{jobId}/content`（保存）
- `POST /api/files/job/{jobId}/create`
- `POST /api/files/job/{jobId}/mkdir`
- `POST /api/files/job/{jobId}/rename`
- `DELETE /api/files/job/{jobId}/delete`
- `POST /api/files/job/{jobId}/upload`

**安全约束**：
- 必须校验路径，禁止目录穿越
- 仅允许访问 `generated-code/job-{id}`

### Task 5：预览服务后端管理
**目标**：启动/停止/重启生成项目的前后端服务  
**要点**：
- 新增 `PreviewService` 管理进程句柄与状态
- 读取生成项目 `application.yml` 中的端口配置
- 端口避开 3000/8080（配置校验 + 默认兜底）
- 单实例运行（若已有运行实例则提示或要求先停止）

**建议配置示例**（写入生成项目的 `application.yml`）：
```yaml
preview:
  frontendPort: 3001
  backendPort: 8081
```

### Task 6：预览面板前端
**目标**：iframe 预览 + 控制按钮  
**要点**：
- 预览 Tab 内嵌 iframe
- 启动/停止/重启按钮
- 状态展示（启动中/运行中/已停止/重启成功）

### Task 7：对话流状态与链接展示
**目标**：对话流显示状态与预览链接  
**要点**：
- 展示“启动中/运行中/已停止/重启成功”
- 展示“Web 预览地址/打开预览链接”

### Task 8：并发限制与扩展预留
**目标**：单实例运行并为多实例做扩展预留  
**要点**：
- 内存记录当前运行 jobId 与进程
- 新启动时校验是否已有实例
- 设计接口返回明确的冲突提示

### Task 9：测试与验收
**功能测试**：
- 对话流生成后样式不变形
- “确认启动”出现且生效
- 文件树/编辑/保存/上传/重命名/删除全部可用
- 预览可启动/停止/重启，iframe 显示正确
- 对话流状态与链接可见

## 执行流程

```
生成完成
  ↓
对话流显示“确认启动”
  ↓
用户点击确认
  ↓
后端读取生成项目 application.yml 端口
  ↓
启动前端/后端预览进程
  ↓
对话流展示状态与预览链接
  ↓
预览 Tab iframe 展示页面
```

## 验收标准
- 代码生成后对话区样式不再变乱，宽度/气泡/字体/间距/对齐保持稳定  
- 生成完成后对话流出现“确认启动”按钮，点击后才启动服务  
- 文件浏览器仅能访问生成目录，支持新建/删除/重命名/新建文件夹/上传  
- 文本文件可编辑并可保存；二进制文件只读  
- 预览服务可启动/停止/重启，且使用配置端口（避开 3000/8080）  
- 预览结果在“预览”标签内嵌显示  
- 对话流展示运行状态与 Web 预览地址/打开链接  

## 风险与对策
- 预览进程异常退出：增加状态检测与重启按钮
- 端口冲突：读取配置后校验，不合法时给出提示
- 文件操作安全：严格路径校验，禁止目录穿越
