## 目标
实现代码生成后自动上传到 GitLab 仓库，包括：
1. 根据需求编号创建 GitLab 群组
2. 在群组下创建前端和后端项目
3. 推送生成的代码到 GitLab
4. 触发 GitLab Pipeline
5. 等待 Pipeline 完成
6. 查看并记录 Pipeline Artifact

## 执行流程

```
生成代码完成后
  ↓
创建 GitLab 群组（如果不存在）
  ↓
创建前端项目（如果不存在）
  ↓
创建后端项目（如果不存在）
  ↓
推送前端代码
  ↓
推送后端代码
  ↓
触发前端 Pipeline
  ↓
等待前端 Pipeline 完成
  ↓
触发后端 Pipeline
  ↓
等待后端 Pipeline 完成
  ↓
记录 Pipeline 结果和 Artifact
  ↓
更新作业状态为 SUCCESS
```

## 验收标准
1. 代码生成后能在 GitLab 上找到对应的群组
2. 群组下有前端和后端两个项目
3. 两个项目都包含生成的代码
4. 两个项目的 Pipeline 都能触发并成功运行
5. 作业记录中包含 GitLab 相关信息（群组ID、项目ID、Pipeline ID等）
6. 能通过作业详情页面查看 Pipeline 状态和 Artifact
